# Licenses and attribution

Life Ops source and documentation use the [MIT License](../LICENSE). Preserve
that notice when redistributing the source or substantial portions of it.

Python dependencies are installed separately from the pinned requirements files;
they are not relicensed by Life Ops. Their distributions include their own license
notices. GitHub Actions and security scanners also retain their upstream licenses.
Keep those notices when distributing bundled dependencies or container images.

Optional forecasts come from [Open-Meteo](https://open-meteo.com/), whose weather
data is provided under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
The weather card links the source and license and identifies the Life Ops summary.
Preserve that attribution when restyling the card. Data licensing and service
access are separate; review the provider's current [terms](https://open-meteo.com/en/terms)
before choosing an API plan or deployment. See [weather setup](onboarding/weather.md).

Public examples and test records are fictional. This starter does not bundle
personal records, third-party logo images, or provider credentials. If you add
images, fonts, imported records or other assets to your own installation, check
their source and permissions before redistributing them.
