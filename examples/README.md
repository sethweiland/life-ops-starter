# Fictional examples

All people, projects, routines and teams used by the examples and test fixtures are
demonstration data. No example represents a live account or an active automation.

The application never loads `routines.json` automatically. To try it locally, enable
`modules.grok_bot` in your private configuration and copy it to
`data/grok_bot_routines.json`. Do not connect a demo to production storage.

Replace the example records with your own private catalog when ready. An enabled
flag describes an external routine; it does not start anything from the dashboard.
